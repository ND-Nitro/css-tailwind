# AI Usage Log

During this project, I used AI as a support tool for planning, debugging and improving my workflow. AI was used to help explain errors, suggest possible solutions and improve my understanding of Tailwind CSS, Vite and GitHub Pages deployment.

I used AI to help with the following areas:

- Understanding how to structure a static multi-page project with Vite.
- Debugging Tailwind CSS issues when the deployed page appeared as plain HTML without styling.
- Understanding the difference between source files and the built `dist` folder.
- Setting up the correct Vite base path for GitHub Pages.
- Fixing the multi-page build configuration so that `index.html`, `feed/index.html`, `profile/index.html` and `about/index.html` were included in the production build.
- Improving HTML validation, including password validation with `minlength` and `pattern`.
- Improving written content for the profile cards, feed cards and project reflection.
- Getting suggestions for layout improvements, such as making the profile card smaller and more relevant to a frontend student profile.
- Creating a clearer project reflection structure.

AI was not used as a replacement for my own work. I used the suggestions as guidance, tested the changes myself, adjusted the code manually and made the final decisions for the design, structure and content. The project was built, tested and deployed by me.

I also discussed some of the same issues with Mia, since we experienced similar problems during the project. Her feedback helped me understand mistakes I had missed, especially around debugging, file paths and GitHub Pages deployment. Working together made the learning process more effective than trying to solve everything alone.
