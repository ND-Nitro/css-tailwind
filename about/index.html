Welcome to SocialApp

A simple social media concept for frontend practice

SocialApp is a static front-end prototype built to practice layout, responsive design, forms and reusable page structure with Tailwind CSS.

View profile Explore feed

Authentication

Static login flow

The login and register forms use HTML validation and send the user to the profile page as part of the static prototype.

Feed

Social content layout

The feed page includes post cards, images, search, sorting and a create-post form to show the structure of a social app.

Profile

Developer profile

The profile page presents user information, posts, follower numbers and a small tech stack section.

Project purpose

Built to practice CSS frameworks

This project focuses on using Tailwind CSS to create a responsive interface with clean spacing, accessible forms, card layouts and consistent navigation between pages.
